#### Fix: Microsoft Office 2021 Business Pro License Issue on macOS

If you purchased a perpetual **Microsoft Office 2021 Business Pro** license for Mac and encountered activation errors (such as missing license or disabled editing) after **October 2026**, your suite likely auto-updated to a build that strictly requires a Microsoft 365 subscription. 

Below are the direct links to the official Microsoft CDN for the last functional builds that fully support your perpetual 2021 license, along with instructions on how to prevent the issue from reoccurring.

⚠️ **Important:** Before running the downloaded .pkg installer, make sure to completely close all Office applications and move the existing Microsoft Word, Excel, PowerPoint, and Outlook apps from your Finder -> Applications folder into the **Trash**. 

#### 🛑 Step-by-Step: How to Disable Auto-Updates

To prevent *Microsoft AutoUpdate* from automatically pulling the broken newer version again, you must disable the background update feature immediately after installing the package. 

1. Open any installed Microsoft Office application (e.g., **Word** or **Excel**).
2. Click on **Help** in the top menu bar.
3. Select **Check for Updates**.
4. In the *Microsoft AutoUpdate* utility app that opens, **uncheck** the box labeled:
"Automatically keep Microsoft apps up to date".
